# Требования

## Функциональные требования:

### Этап 1: Поиск производителей

- Реализовать поле ввода для ввода артикула (номера) автозапчасти.
- По факту ввода выполнять запрос к API для получения списка производителей (брендов), выпускающих деталь с данным артикулом.
- Отобразить полученный список производителей для выбора пользователем.

### Этап 2: Получение аналогов и предложений

- При выборе пользователем конкретного производителя инициализировать повторный запрос к API. Передав номер и бренд.
- Отобразить итоговую таблицу (или список) найденных аналогов и предложений.
- Для каждой позиции обязательно вывести следующие данные:
  - Название / Производитель
  - Стоимость (цена)
  - Доступный остаток на складе

## Технические требования:

**Стек:** React, с использованием Redux, без TypeScript.

**Стилизация:** на ваше усмотрение _(желательно CSS Bootstrap)_.

**Архитектура**: корректная обработка состояний загрузки _(компоненты-лоадеры)_ и возможных ошибок от API _(обработка пустых ответов, сбоев сети)_. Но при этом – чем проще, тем лучше.
